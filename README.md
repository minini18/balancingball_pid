# 🤖 Ball Balancing Robot Simulation

아두이노 기반 볼 밸런싱 로봇(Ball and Beam) 및 PID / 강화학습 제어 웹 시뮬레이션 프로젝트입니다.

---

## 🌟 주요 기능 및 모드 안내

### 1. [모드 1] 기본 밸런싱 시뮬레이션 (`index.html`)
- 키보드 좌/우 방향키를 이용한 수동 제어
- 랜덤 모드, 위치 기반 오토 모드, 기본 PID 제어 및 Q-Learning(RL) 지원

### 2. [모드 2] 아두이노 연동 모드 (`index2.html`)
- 실제 아두이노 소스코드(`balancing_robot.ino`)의 서보 모터 각도 및 초음파 센서 로직 반영
- 아두이노 PID 제어 및 강화학습 학습 곡선(Survival Time 그래프) 시각화

### 3. [모드 3] 레벨별 난이도 & PID 튜닝 랩 (`index3.html`)
- **난이도 레벨 선택**:
  - **🟢 레벨 1**: 기본 크기 ($R=16\text{px}$) & 표준 중력 ($G=981$)
  - **⚡ 레벨 2**: 중력/공 속도 증가 ($G=2200$)
  - **🔥 레벨 3**: 소형 공 ($R=9\text{px}$) & 초고속 가속 ($G=3500$)
- **정밀 PID 제어기**:
  - P(비례), I(적분), D(미분) 게인 슬라이더 및 수치 직접 입력
  - 실시간 PID 기여도 분해(각도 기여량 시각화)
  - 실시간 위치 및 오차 수렴 곡선 오실로스코프
  - 외란 주기(공 튕기기) 및 4가지 추천 프리셋 제공

---

## 🚀 로컬 실행 방법

별도의 복잡한 설치 없이 웹 브라우저에서 바로 실행하거나, 로컬 웹 서버를 통해 실행할 수 있습니다.

### Python 내장 서버로 실행:
```bash
python -m http.server 8000
```
브라우저에서 `http://localhost:8000/index3.html` 접속
